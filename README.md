# Stellar Burgers

Приложение для создания космических бургеров. Пользователь может собрать бургер из ингредиентов, оформить заказ, посмотреть ленту заказов и данные своего профиля.

## Ссылка на проект

https://varyandis.github.io/react-burger/

## Запуск проекта

Установить зависимости:

```bash
npm ci
```

Запустить проект:

```bash
npm run dev
```

Собрать проект:

```bash
npm run build
```

## Тестирование

Запуск тестов редьюсеров:

```bash
npm test
```

Запуск Playwright-тестов:

```bash
npm run e2e
```
